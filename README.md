# git_KAIZEN

New atLIB Service Operating Platform project.

This repository is intentionally treated as a new system rather than a Web rewrite of the existing DDL prototype.

Core direction:

- Service × Contract × Recipient
- Progressive Onboarding
- Work-driven Operational Context
- Fact / Unknown / Observation separation
- Requirement evaluation before Work creation
- Work → Action → Change → Registry / Knowledge
- Progressive Authority
- Learning Loop
- Continuous KAIZEN
- One Platform / Multiple Service Models

Initial target service models:

1. Service Desk
2. 情シスKAIZEN

Existing atLIB systems may be reused selectively for authentication, multi-tenant infrastructure, deployment, audit, and other proven platform capabilities after architecture review.
