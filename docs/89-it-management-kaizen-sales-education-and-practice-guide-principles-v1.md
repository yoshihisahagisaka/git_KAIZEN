# IT経営KAIZEN — 営業教育・実践ガイド設計原則 v1

Status: **CANONICAL — BUSINESS / SALES ENABLEMENT**  
Date: 2026-09-16

## 1. Purpose

IT経営KAIZENの営業Playbookは、役員向けの一回限りの説明資料ではなく、今後の営業メンバー教育と実際の営業活動で継続利用する **「IT経営KAIZEN 営業実践ガイド」** として設計する。

## 2. Core Decision

> **説明会で理解し、営業現場で使い、商談後に振り返れるガイドブックとする。**

用途は以下を含む。

- 役員・営業メンバーへの初回説明 / 教育
- 新しい営業メンバーのオンボーディング
- 商談前の確認
- 商談中の行動ガイド
- 商談後の記録・振り返り
- IT経営KAIZEN営業思想の標準化

## 3. Editorial Principle

資料は原稿を単純にサマライズしたプレゼンテーションにしない。

各重要テーマについて、必要に応じて以下を残す。

1. 考え方
2. なぜそうするのか
3. 実際の会話例
4. NG例 / 従来営業との違い
5. 迷ったときの判断基準 / 覚える一言

> **原稿 → 要約 → スライド** ではなく、**原稿 → 読みやすく編集 → 図解を添える** を基本とする。

ページ数を先に固定せず、読めば理解でき、後から現場で参照できる情報量を優先する。

## 4. Core Sales Behavior

営業現場では以下の5つを基本行動とする。

> **事業を知る → 会社の未来を聞く → 変えたいことを聞く → ITとの関係を聞く → 次の約束をする**

加えて、以下を重要行動原則として教育する。

- 確認できたことを記録する
- 「まだ分かっていない」ことも重要な情報として記録する
- 私たちの仮説と確認できたことを混ぜない
- その場で答えを決めない
- 答える前に、もう一つ聞く
- 既に分かっていることは聞き直さず、足りないことを確認する
- 最後は経営者自身が決める

## 5. Why We Do Not Decide the Answer in the Meeting

「その場で答えを決めない」は、単に情報不足だからではない。

> **経営者自身が考え、比較し、決める機会を阻害しないためである。**

経験豊富な役員・営業・コンサルタントほど、顧客の話から解決策が早く見える場合がある。その経験知は捨てず、まず「私たちの仮説」として保持する。

IT経営KAIZENの役割は、経営者に代わって答えを決めることではなく、必要な事実と選択肢を揃え、経営者自身が判断できる状態をつくることである。

営業現場の合言葉：

> **答える前に、もう一つ聞く。**

## 6. Guidebook Operating Cycle

ガイドは以下の循環で利用する。

> **読む → 理解する → 実際に使う → 振り返る → 身につける**

営業前・営業中・営業後のチェック項目を持ち、チェックできなかった項目は失敗判定ではなく次回のKAIZEN材料として扱う。
