# Managed Capability — Three Representative Commercial Cases v1

Status: **BUSINESS HYPOTHESIS / SENSITIVITY MODEL — NOT PRICE DECISION**  
Date: 2026-09-13

## 1. Purpose

doc57のAssessment → Commercial Scope Decision Modelを3つの架空顧客へ通し、企業規模、Complexity、Human Work Structure、FACTACT Leverage、Delivery COGS、Price Scenarioの関係を見る。

全ての顧客像・時間・圧縮率・原価はHYPOTHESIS。実案件FACTではない。

---

## 2. Common Principles

> Human Work Hours ≠ Human Work Cost ≠ Human Work Complexity ≠ Customer Value

> Priceから仕事を作らない。FACTからScopeを作る。

Customer Baseline WorkとatLIB Managed Scopeを分離する。

また、atLIB Managed ScopeのBaseline Human WorkとFACTACT適用後Required Human Workも分離する。

# CASE A — 100名 / Standardizing Growth Company

## 3. Company Context — HYPOTHESIS

- Employees: 100
- Devices: 120
- SaaS / Systems: 10–15
- Locations: 1–2
- Group companies: 0–1
- IT staffing: Generalist 1名または兼任
- Approval: relatively simple
- Security / Governance: basic–medium
- Vendor count: small–medium

### FUTURE example

「一人情シス依存を減らし、入退社・Account・Device・SaaS運用を標準化し、経営者がITの状態を把握できる。」

## 4. Current Work — HYPOTHESIS

Total customer IT recurring work: 120h/month.

6 Lenses / Actor Allocation後：

- Eliminate / Automate / Project: 20h
- Customer retains: 20h
- Existing vendor / other actor: 10h
- atLIB Managed Scope baseline: **70h**

Managed Scope composition hypothesis:

- Service Desk / Communication: 25h
- Operational: 30h
- Management / Reporting: 15h

Human Work nature:

- Routine / Operator dominant
- Limited specialist work
- Relatively low approval complexity

## 5. FACTACT Leverage — HYPOTHESIS

Compression assumption: **45%**

70h → **38.5h Required Human Work**

Drivers:

- duplicate registry update elimination
- standard Joiner / Leaver flow
- SaaS / Device context connection
- reporting from operational FACT
- knowledge reuse

## 6. Economics — HYPOTHESIS

Sensitivity example only:

- Blended Human Full Cost: ¥4,000/h
- Human Work Cost: 38.5h × ¥4,000 = ¥154,000
- Non-Human Delivery Cost: ¥100,000
- Delivery COGS: **¥254,000/month**

Price scenario margin:

- ¥498k → approx. 49.0%
- ¥600k → approx. 57.7%
- ¥800k → approx. 68.3%

### Interpretation

¥498k may be economically possible under this hypothesis, but Customer Value / willingness-to-pay is UNKNOWN.

At 100 employees, cost viability may exist before value-price viability. The commercial risk may be **customer budget / value pool**, not only delivery cost.

# CASE B — 300名 / Shared Capability Sweet-Spot Candidate

## 7. Company Context — HYPOTHESIS

- Employees: 300
- Devices: 350
- SaaS / Systems: 20–35
- Locations: 2–5
- Group companies: 1–3
- IT staffing: 1–3 Generalists
- Approval: department / authority patterns
- Security / Governance: medium–high
- Vendor count: medium
- IT investment: materially larger than Case A, but actual amount UNKNOWN

### FUTURE example

「日常運用に追われる情シスから脱却し、Security・IT Governance・DXを進められるIT Functionへ変える。」

## 8. Current Work — HYPOTHESIS

Total customer IT recurring work: 220h/month.

6 Lenses / Actor Allocation後：

- Eliminate / Automate / Project: 35h
- Customer retains: 35h
- Existing / specialist vendor: 30h
- atLIB Managed Scope baseline: **120h**

Managed Scope composition hypothesis:

- Service Desk / Communication: 35h
- Operational: 55h
- Management / Reporting / Vendor: 30h

Human Work nature:

- Operator + Engineer + Management mix
- more approval / authority verification
- multi-system effect verification
- security / audit evidence
- vendor coordination

## 9. FACTACT Leverage — HYPOTHESIS

Compression assumption: **50%**

120h → **60h Required Human Work**

Compression is not assumed to come from faster human execution alone.

Expected drivers:

- Work → multiple management projections
- account / device / SaaS relation reuse
- evidence reuse
- standard operational execution
- context search reduction
- management reporting without duplicate input
- shared specialist only when required

## 10. Economics — HYPOTHESIS

Sensitivity example:

- Blended Human Full Cost: ¥5,000/h
- Human Work Cost: 60h × ¥5,000 = ¥300,000
- Non-Human Delivery Cost: ¥130,000
- Delivery COGS: **¥430,000/month**

Price scenario margin:

- ¥498k → approx. 13.7%
- ¥600k → approx. 28.3%
- ¥800k → approx. 46.3%
- ¥1.0m → approx. 57.0%

### Interpretation

Under this hypothesis, ¥498k is structurally weak and ¥600k is still tight. ¥800k begins to approach a potentially sustainable band.

However, this does **not** decide ¥800k as price.

The customer-side question is whether the Managed Capability delivered is equivalent or superior to alternative IT Function procurement at materially higher TCO.

This case appears most aligned with the current Shared Capability + FACTACT thesis.

## 12. Current Work — HYPOTHESIS

6 Lenses / Actor Allocation後：

## 14. Economics — HYPOTHESIS

Sensitivity example:

- Blended Human Full Cost: ¥5,500/h
- Human Work Cost: 93.5h × ¥5,500 = ¥514,250
- Non-Human Delivery Cost: ¥170,000
- Delivery COGS: **¥684,250/month**

Price scenario margin:

The larger customer may have a larger value pool and alternative TCO, but also materially higher Delivery Complexity.

## 16. Important Finding — Price Curve is Not Linear

The model suggests a non-linear relationship.

```text
Company Scale ↑
  → Work Volume ↑
  → Complexity / Responsibility ↑
  → Specialist Mix ↑
  → Customer Value Pool ↑

but simultaneously

FACTACT / Standardization / Shared Capability
  → Human Dependency ↓
```

Therefore price should not scale linearly with employee count or Human Hours.

The commercial opportunity exists where:

> **Customer-side IT Function Value grows faster than atLIB Required Human Work / Delivery COGS.**

This is the economic definition of the candidate **Leverage Zone**.

---

## 17. Candidate Leverage Zone — HYPOTHESIS

Case analysis strengthens, but does not prove, the hypothesis that approximately 100–500 employee companies may contain a useful Leverage Zone.

Within that broad range, Case B-like companies may be especially attractive:

- IT environment already meaningful
- Generalist model under pressure
- Specialist Capability needed intermittently
- enough recurring Work to create FACTACT leverage
- enough IT investment / business impact to create Value Pool
- not yet so Enterprise-specific that Shared Capability loses efficiency

This is an **ICP HYPOTHESIS**, not DECISION.

---

## 18. Another Important Finding — 49.8 / 60 / 80 are Different Commercial Conditions

The three prices should not be treated as small / medium / large employee tiers.

Under the example assumptions:

### ¥498k
May require:
- relatively narrow Managed Scope
- high standardization
- low specialist intensity
- low service complexity
- strong FACTACT leverage

### ¥600k
May support:
- somewhat broader Scope
- moderate complexity
- moderate specialist / service management requirement

But Case B shows ¥600k can still be insufficient if 60h of mixed capability Human Work remains.

### ¥800k
May support:
- broader IT Capability
- higher complexity / responsibility
- more Engineer / Management mix

But Case C shows ¥800k can also be insufficient.

Therefore:

> **Price is an output of Scope Economics, not an employee-size label.**

## 19. Customer Alternative TCO — Still UNKNOWN

The model has not yet proven customer-side economic advantage.

User-provided business scenario:

> Equivalent IT Function delivered through three onsite person-months may exceed ¥2m/month.

This is a USER-PROVIDED SCENARIO, not an externally validated universal market FACT.

For actual Assessment, compare:

- current internal FTE cost
- dispatch / onsite cost
- existing vendor cost
- specialist vendor cost
- hidden employee / management work
- IT downtime / waiting cost where measurable
- SaaS / license / infrastructure spend

A Managed Capability price can only be called attractive after comparing equivalent Capability Coverage / Quality / Risk, not only hours.
